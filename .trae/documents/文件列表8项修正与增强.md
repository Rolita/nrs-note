# 文件列表：8 项修正与增强

## Context（为什么要改）

上一轮把「文件」视图接成了真实文件夹树（[vault_tree.dart](file:///c:/Users/Kotori/Desktop/nrs-v5/lib/ui/shell/vault_tree.dart)），跑通后发现 8 个问题：新建笔记标题不递增、选中行内容与高亮没对齐、新建文件夹多一次弹窗、空文件夹多一行斜体提示、缺重命名与移动、缺拖拽、多余的小图标。本次逐条修掉，并补上重命名／移动到文件夹／拖拽移动所需的**控制器与存储能力**（当前代码只有"打开/置顶/收藏/删除"，没有任何"改路径"的操作）。

## A. 树视图的小修（`lib/ui/shell/vault_tree.dart`）

1. **选中行对齐（问题 2）**：`_FileRow` 用 `Stack` 包 `Row`，而 `Stack` 的默认 `alignment` 是 `topStart`，且根目录行没有 `_IndentGuides`（stretch 子项）时 `Row` 的天然高度只有约 15px，于是 15px 的内容被贴在 28px 行高的顶部 —— 这就是截图里"高亮块有了、图标文字却偏上"的原因。修法：`Stack(fit: StackFit.expand, ...)`（让 `Row` 吃满 28px）+ `Row(crossAxisAlignment: CrossAxisAlignment.center)`。
2. **不显示空文件夹提示（问题 4）**：`_rows` 不再生成 `_TreeRow.emptyFolder`，删掉 `_EmptyFolderRow`；展开空文件夹就是什么也不显示。
3. **去掉小图标（问题 8）**：`_FolderRow` 删掉文件夹 `Icon`，`_FileRow` 删掉 `Icons.description_outlined`；保留文件夹的展开箭头，文件行保留 19px 缩进占位，好让文件名与文件夹名左对齐。

## B. 侧边栏行为（`lib/ui/shell/note_list_panel.dart`）

4. **新建文件夹不再弹窗（问题 3）**：`_createFolder` 直接 `await notes.createFolder('新建文件夹')`（`_freeFolderName` 已经会给出「新建文件夹 2」）→ `revealFolder(path)` → toast，和 `_createNote` 一样是"点一下就有"。

## C. 控制器与存储（问题 1、5、6、7 的公共底座）

`lib/state/notes_controller.dart`

5. **新建笔记标题递增（问题 1）**：`createNote` 现在先 `Note.blank(title: name)`，再用 `_freeName` 只改 `fileName`，标题始终是「未命名」。改为**先算文件名再据其派生标题**：`fileName = _freeName(blank.fileName, folderPath: folder)`，`title = fileName 去 .md`；这样 `未命名 2.md` 对应的标题就是「未命名 2」，两者永远一致。
6. **`renameNote(Note note, String title)`**：改标题 → `fileName = _freeName(Note.buildFileName(title), exceptId: note.id, folderPath: note.folderPath)`（已有方法，会自动加 ` 2`）→ `_store.save(note, previousPath: note.relativePath)`（`IoNoteStore.save` / `WebNoteStore.save` 都会删掉旧文件）；若该笔记正是打开的 `draft` 就同步更新。`updateTitle` 只服务于"当前打开的那篇"，这里不能复用。
7. **`moveNotes(List<Note> targets, String targetFolder)`**：逐篇把 `folderPath` 换成目标文件夹并在该文件夹内重新 `_freeName`，**边算边 `_replace`**，这样同一批里两篇同名 `未命名.md` 一起搬进同一文件夹时不会撞名；每篇用 `_store.save(updated, previousPath: old.relativePath)`（IO 的 `save` 会 `create(recursive: true)` 父目录，所以搬进新文件夹也能落盘），最后 `refresh(keepSelection: true)` 同步文件夹列表。
8. **`renameFolder(String folderPath, String newName)`** + 存储层 `renameFolder(String from, String to)`：
   - 基类 `NoteStore` 增一个默认实现（返回 `false`）；
   - `IoNoteStore`：`Directory(_pathFor(from)).rename(_pathFor(to))`，目标已存在则失败返回 `false`（不覆盖别人的目录）；
   - `WebNoteStore`：把 `nrs/v1/file/<from>/…` 的 key 重写成 `<to>/…`，同步 `_folders` 与 `_flush()`；
   - 控制器侧：父目录内用 `_freeFolderName` 去重、若 `activeFolder` 落在被改名目录里则改写到新路径，然后 `refresh(keepSelection: true)`（笔记 id 来自 front matter，选区不会丢）。

## D. 树的交互（问题 5、6、7）

9. **右键菜单 + 内联重命名（问题 5）**：菜单在「打开/置顶/收藏」后追加「重命名」(hint: F2) 与「移到文件夹…」，删除仍在最后。重命名不是弹窗——该行就地变成 `TextField`（autofocus、全选当前名、Enter 提交、Esc 取消、失焦提交），文件名与文件夹名都用同一套。
10. **F2（问题 5）**：树外层加 `Focus`，点击任意行时 `requestFocus`；`onKeyEvent` 捕获 F2 → 对选区中最后点击的那一项启动重命名。**不做成 AppShell 的全局快捷键**，否则在编辑器里打字时按 F2 会误改文件名。
11. **右键「移到文件夹…」（问题 6）**：多选时作用于整个选区（和删除同一套规则）；点开一个文件夹选择对话框（首项「根目录」+ 所有文件夹按路径缩进列出）→ `moveNotes`。
12. **拖拽（问题 7）**：
    - `_FileRow` 包 `Draggable`，`onDragStarted` 里先保证被拖的行在选区内（未选中则单选它），拖动的是**整个选区**；载荷用一个持有树状态的小对象，落点处再读取当前选区（`Draggable.data` 在拖动开始时求值，早于 `onDragStarted`，直接传 `List<Note>` 会拿到旧选区）。
    - `_FolderRow` 包 `DragTarget`，悬停高亮该行，松手 → `moveNotes(..., 该文件夹)`；目标文件夹与笔记当前位置相同时拒绝接受。
    - 「回到根目录」用一个**显式落点**：拖动进行中在列表末尾插一条「移到根目录」投放条，避免"把已经在该文件夹里的笔记拖到该文件夹行上"时穿透到外层根区而意外搬到根目录。

## 明确不做

- 不动搜索／标签两个视图。
