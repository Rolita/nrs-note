矩形内所有文字按行优先并入左上角，换行在源文件里是 <br>；覆盖格清空。拆分只去掉跨度，文字全部留在锚点，一次撤销。

颜色是令牌，不是固定色值

浅色 Aa Aa Aa Aa Aa Aa
深色 Aa Aa Aa Aa Aa Aa
灰 · 琥珀 · 绿 · 蓝 · 紫 · 红

预设写成语义令牌，明暗主题各自取值；只有自定义色才写入 #RRGGBB，未指定文字色时按底色自动选可读文字色。

色板

220px 浮层，挂在 overlay 上，不被 252px 面板裁切。六个预设、无填充、自定义…；当前格颜色打勾，混选不打勾。

填充色带透明度，文字色不带；自定义打开现有取色器，确认后才落一次编辑。

合并之后

点合并块任何位置都落到左上角锚点；Tab 跳过被覆盖的格子；查找把光标放进覆盖格时，这张表临时按未合并显示，作为源码逃生门。

移行、排序、去重、转置会拆掉合并（同一步撤销），但保留颜色；清空内容、改对齐、插入行/列都会保住合并。

源文件里长这样

| 地区 | 指标 | 本周 | 变化 |
| --- | --- | --- | --- |
| <!--nrs r=2 bg=blue-->华东 | 新增笔记 | 42 | +10.5% |
|  | 平均字数 | 680 | −4.5% |
| 华南 | 新增笔记 | 31 | +6.9% |
| <!--nrs c=4 bg=amber fg=red-->**注意** · 数据只统计已同步的笔记 |  |  |  |

指令是单元格开头的 HTML 注释，键序固定 c r bg fg。GitHub、Obsidian 阅读视图会隐藏它，普通表格不写任何注释。

跨度和颜色只占源码字符位，渲染时替换成零宽字符；光标、选区、输入法全部沿用现有偏移体系，不会整体错位。

外部打开时看到的是「未合并、无颜色」的普通表格：文字仍在原位，只是没有格式，不会变成乱码。
