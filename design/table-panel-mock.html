入口与互斥

  • 标题栏右侧，大纲按钮的右边新增一个 32×32 表格图标按钮，图标用 table。
  • 三态互斥：大纲开 / 表格开 / 都收起。点已选中的按钮即收起。
  • 两个按钮同一套选中态：accentSoft 底 + 左侧 2px accent 竖线。
  • 面板开时按钮组与面板左边缘对齐；都收起时并排停在窗口按钮左侧。

面板

  • 宽度沿用 232px 默认值、可拖拽调宽，窗口窄于 980px 时与大纲一起让位给正文。
  • 底色 sidebar，与大纲、文件栏同一步；仅靠 1px 发丝线分隔。
  • 头部 32px：「表格」+ 列 × 行；下方一块「当前表格」信息条。
  • 分组顺序：选择 → 行 → 列 → 排序 → 对齐 → 汇总 → 数据 → 表格；组间用 outlineSoft 细线，内容区可滚动。

工具（对齐 Excel 常用操作）

  • 选择：整行 / 整列 / 整张表。
  • 行：上/下插入、复制、上移、下移、删除。
  • 列：左/右插入、复制、左移、右移、删除。
  • 排序：按当前列升序 / 降序，数字按值、文本按拼音，表头不动。
  • 对齐：左 / 中 / 右 + 自动（数字列贴右、文本列贴左）。
  • 汇总：合计 / 平均 / 计数 / 最小 / 最大，追加成表尾一行。
  • 数据：向下填充、向右填充、按本列去重。
  • 表格：表头开关、转置、清空所选、删除整张表格。

实现状态

  • 已有命令：插入 / 删除 / 移动 / 复制行列、排序、自动对齐、汇总行、转置、清空。
  • 需新增：整行 / 整列 / 整表选择（设置选区）、向下 / 向右填充、按列去重。
  • 面板只是这些命令的第二种入口，右键菜单保持不变。

没有表格时

  • 光标不在任何表格内：正文区居中显示空态，只留一句「把光标放进表格」。
  • 不用操作成功提示；操作结果直接体现在正文里。
  • 表格结构被改坏（不再是合法表格）时，面板自动回到空态。
