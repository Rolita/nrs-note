编辑区和侧边栏都能分块

两者用的是同一个分割组件——一棵二叉分割树。区别只在叶子里装什么： 编辑区的叶子装文档（笔记 / 图谱 / 白板 / 图片），侧边栏的叶子装视图（文件 / 书签 / 搜索 / 标签）。 这个原型可以直接拖：把顶部标签拖到任意格子的边缘试试。

拖标签到格子中间＝在这个格子里打开；拖到四条边＝把格子切成两半。拖格子之间的细线改比例（侧边栏那条也能拖），双击细线均分。

一棵二叉分割树，两处共用

每次分割只把一个格子换成「两个格子 + 一条细线」，所以任意格子的任意边都能继续切——这就是「随意」的来源，网格做不到。 编辑区和侧边栏各持有一棵这样的树，渲染代码是同一份（paint(容器, 树, 画叶子的函数)）。

每格记什么

  • 编辑区叶子：装哪个文档（note id / 白板路径 / 图片路径 / 图谱）、滚动位置
  • 侧边栏叶子：装哪个视图（文件 / 书签 / 搜索 / 标签）、展开状态、滚动位置
  • 内部 split：方向（左右 / 上下）、比例（0–1）、两个子节点
  • 两棵树各自序列化成 JSON 存进会话，重启原样恢复

和现在代码的差别

  • EditorPane 和 NoteListPanel 都是单例，要各拆成一个 SplitHost
  • MainView 和 SidebarView 两个全局枚举，都变成 per-pane 字段
  • 顶部标签条从「切换全局视图」变成「拖进某个 pane」，点了就落在当前聚焦的那格
  • notes.selectedId 不能再全局唯一——每格要能显示不同笔记
  • 侧边栏底部那条（vault 名 / 帮助 / 设置）留在分割外面，不属于任何一格
