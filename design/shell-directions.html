四个方向：不是换色，是换一套语言

上一版只动了配色和细节，壳子还是那个壳子。这一回四个方向连结构一起改： 面板是悬浮还是贴边、标签是药丸还是铭牌、侧栏是列表还是索引卡、字是黑体还是宋楷、 分隔靠发丝还是靠光。四张图里内容完全一样（同一篇《九月复盘》、同一棵树、同一份大纲）， 只有语言不同——这样比才公平。

四个方向的差别到底在哪

  • 结构A 把面板从窗口边缘拿下来（有缝）；B/C/D 贴边，靠线、光、纸分出层次。
  • 标签A 药丸、B 缺角铭牌、C 带槽位的插槽、D 贴胶带的纸条。
  • 分隔A 靠阴影与高光、B 靠双线、C 靠 1px 辉光线、D 靠纸纹与页边线。
  • 字A 无衬线、B 宋体 + 首字下沉、C 全等宽、D 楷体标题 + 宋体正文。
  • 重心A 最「现代产品」，B 最「贵」，C 最「硬核」，D 最「私人」。
  • 风险A 的模糊吃 GPU；C 的等宽字读长文偏累；D 的楷体在小字号下会糊。
回我 A / B / C / D

也可以说「B 的框 + C 的字」「D 的纸 + A 的标签」——混的时候我会只取装饰语言，不动结构。

选定后我出可交互的整窗版（悬停、选中、切标签都能点），再谈落到 Flutter 的顺序。
