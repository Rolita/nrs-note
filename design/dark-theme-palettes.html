五套深色：四块 chrome 只用一个色

定稿 · 石墨 + 靛紫

现在顶栏、功能栏走 canvas，左右侧栏走 sidebar，四块壳子是两个颜色， 中间的 1px 线还要再画三道。这一轮把它们合成一个令牌 chrome： 顶栏 = 功能栏 = 左栏 = 右栏 = 同一个色，四块之间一条线都不画，只在 chrome 与编辑区之间留一道发丝。 编辑区仍是全场最亮的那张纸，chrome 压到它下面 0.8 个百分点，靠这个台阶分开，不靠描边。

定稿另外把强调拆成两层：壳子（顶栏 / 功能栏 / 左右栏）用石墨的近白，只做「你现在在哪」的标记； 编辑区里的强调换成午夜靛的靛紫，管选中文字、表格选中格、链接和勾选框。同一个屏幕上，两种强调各管一件事。

落代码要做三件事其余原样
  • 并 chromecanvas 与 sidebar 合成一个 chrome，顶栏 / 功能栏 / 左右栏全取它，四块之间不画线。
  • 壳强调不动accent / accentHover / accentSoft / onAccent / selectionEdge 保持石墨的近白，只做位置标记。
  • 新增纸强调editorAccent / editorAccentSoft / onEditorAccent 三个字段取午夜靛；selection 与表格选中框也改用它。

为什么分两层壳上的近白只回答「你在哪一栏」，纸上的靛紫只回答「选中了哪一段」。两者同色时，眼睛会把「当前行」和「选中的字」看成一回事。

唯一可能要微调editorAccentSoft #23263A 是按午夜靛的纸调的，放到 #202127 上略淡；嫌浅就提到 #262B42。

这五套的共同规矩

  • 四块同色顶栏 / 功能栏 / 左栏 / 右栏 都取 chrome，四块之间不画线。
  • 一道发丝chrome 与编辑区之间只留 outlineSoft，不用边框加阴影互相打架。
  • 编辑区最亮chrome 比编辑区暗 0.7–0.9 个百分点，眼睛落在纸上。
  • 正文达标正文 / 编辑区 ≥ 12.5:1，次级 ≥ 6.4:1，三级 / 顶栏 ≥ 3.6:1。
  • 强调分两层壳子标记位置、纸面标记内容；定稿把这两层拆成两组值，其余四套仍是同一个。
  • 强调色不与语义撞墨青把「成功」让到黄绿，暖炭把强调让成暖白。
  • 表格六色不动那套色是全局颜色语言，五套都原样保留。
  • 白板与图片同底两块主区的底也从 chrome 取，主区之外不会冒出第三种灰。
