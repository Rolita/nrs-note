删除确认面板 · 4 套重构方案

四套方案都替换掉现在的 Material AlertDialog：同样的遮罩、同样的三套主题令牌、同样的间距与圆角阶。差异只在信息密度、按钮位置和存在感。切换主题、亮暗与场景，可以看同一套设计在单篇 / 批量 / 文件夹三种删除下的样子。

四套方案共用的规范

  • 颜色：只用 surfaceRaised / outline / outlineSoft / surfaceSunken / textPrimary / textSecondary / textTertiary / danger / dangerSoft / warning / overlay，不新增令牌。危险按钮的墨色按 AppPalette.readableOn(danger) 计算——暗色主题的浅鲑红会自动落成黑字，不会出现白字糊在浅红上的情况。
  • 几何：间距走 4 / 8 / 12 / 16 阶；圆角 5（目标块）/ 6（按钮）/ 10（对话框）；按钮高 28–30。标题 15–16 / 650，正文 12.5，目标清单 11.5，辅助 10.5。
  • 信息：标题说清删什么；正文永远写明「移入回收站，可在回收站中恢复」；目标块给出真实路径或清单，批量时最多列 5 条 + 「还有 N 篇」。
  • 行为：Esc 与点击遮罩都取消；焦点默认落在「取消」，回车不会误删；关闭 X 等价于取消。

方案信息量存在感最适合
A · 静默确认卡中低单篇删除，日常最高频
B · 危险条卡片高中高批量与文件夹，需要看清清单
C · 底部确认条低中低手不离键盘的快速删除
D · 居中票据卡中高一次带走很多内容、需要停顿一下
