把界面收成一条带子

窗口最上面那条 40px 的带子，同时承担三件事：窗口拖动、文字标签、两个边栏的视图切换。它不该被切成两行。

真正让界面显得脏的，不是某个按钮，而是四个面只差 1.04:1 的明度。纸面、侧栏、顶带挤在同一个灰阶里，眼睛找不到边界，所有 1px 的线都在白费力气。

先把面分开：纸面沉一档，侧栏抬起，顶带跟着侧栏。然后才谈圆角、阴影和字。

顶带只留三段

左边是功能栏的开关，中间是页面自己的标签，右边是右栏的收 / 展和三个窗口按钮。视图图标回到各自的栏里，尺寸统一成 28 的方块、2px 缝、6px 内边距。

  • 文字页 36 高，选中时和纸面同色，只把字提亮，不再画强调线。
  • 图标页 28 方块，选中时一层淡底、图标提亮，底下也不留线。
  • 功能栏同理：中性淡底 + 图标提亮，和列表行的洗色是同一支笔。
  • 侧栏的选中只抬一档中性灰；蓝紫只出现在正文高亮、引用线和列表点上。

这一稿只做配色、尺寸、选中态和窗口面层的 90% 不透明度；强调色只留在正文里，标签、按钮、列表都不再借它表态。字体仍是系统字体（Segoe UI Variable Text + 微软雅黑），换字体要单独出一张样张。

选中态只剩一种语言

标签、按钮、列表都不再借强调色表态，只有正文里的引用线和列表点还留着蓝紫。

侧栏选中抬一档中性灰，悬停再低一档；两档之差就是「你在这里」的全部提示。

把颜色收走之后，界面反而更容易读懂：眼睛只需分辨亮度。

分屏之后，点哪一格，右下角那枚浮片就换成哪一格的行列、待办和字数。浮片本身不动。

  1. 纸面沉到最底。侧栏和顶带抬到 #1E1F21，纸面沉到 #151516——从 1.04:1 到 1.11:1，方向反过来了：正文落在更暗的一面，长时间看时视线落在字上，而不是框上。
  2. 顶部只留两把尺子。所有图标按钮 28、缝 2、左内边距 6；文字页 36；窗口按钮 44。左右栏一致，左栏不再 32、右栏 28。
  3. 选中态统一，不再带强调线。文字页 = 纸色 + 字提亮；图标页 = 中性淡底 + 图标提亮；功能栏 = 中性淡底 + 图标提亮；列表行只留中性洗色。强调色退回正文里的引用线和列表点，标签、按钮、列表上都不再用。
  4. 侧栏选中不再借色。顶带和按钮里的选中底改中性 #34353A，比悬停 #2A2B2F 再亮一档；蓝紫洗色 #2C2D42 只留给正文高亮，像高亮笔。
  5. 顶带不断。右侧拖拽缝在顶部 40px 也画顶带色，右侧那段不再被一条纸色的 5px 缝切开；功能栏顶上 40px 同样永远属于顶带。两侧栏的缝上不画竖线，左右分界只靠侧栏和纸面的色差。
  6. 收起左栏后，功能栏整列并进纸面，只有顶上那 40px 还是顶带色——窗口最上面仍是一条完整的带子。
  7. 透出桌面。窗口面层统一 90% 不透明度（透出一成），文字和缝线保持不透明；这一张的桌面是模拟壁纸，真实窗口的透明层要等落到 Flutter 时再做。
  8. 信息条离开底部。已保存、行列、待办、字数、字符、阅读时间收成一枚浮片，贴在编辑区右下角，编辑栏底部不再为它留一条带子。分屏后点哪一格，浮片就显示哪一格的信息，位置不动。浮片不接收指针事件，压在正文上也不妨碍落点。
  9. 分屏缝补一道 1px 竖线。两格编辑栏是同一种纸色，5px 画布缝太暗，边界会糊掉；在缝心加一道 1px #343438，不把缝撑宽。左右侧栏的缝仍不画线——那里有侧栏和纸面的色差，不需要。
  10. 文件页不再重复计数。左下已经写着「128 篇笔记」，顶上那行「文件 128」就把同一件事说了第二遍；去掉标题和数字，只留四颗动作按钮。
  11. 编辑区右缘多一列标题刻度。平时只有一串 8×2 的短横，间隔 12，当前章节那一道提亮；悬停或聚焦时向左展开 300px 的目录卡。卡里正文 11.5px、行高 26，默认是暗灰的小字配 8×2 的短横，悬停变提亮的粗字配 16×2 的中横，点击当前行再拉到 24×2 的长横，不铺底色；三档短横右缘对齐。平时不占文档宽度，也不挡落点；没有标题时整列消失。分屏时它和右下角的信息浮片一样固定贴在编辑区右缘，只跟随焦点格。右栏的大纲仍保留；若觉得重复，可以再加一条「右栏停在大纲页时收起刻度」的规矩。
